# Intern headshots

Place exactly six JPG headshots in this folder using these filenames:

```text
intern-1.jpg
intern-2.jpg
intern-3.jpg
intern-4.jpg
intern-5.jpg
intern-6.jpg
```

## Image guidelines

- Use a square 1:1 crop.
- Recommended size: 1200 x 1200 pixels.
- Minimum size: 600 x 600 pixels.
- Use JPG format in the sRGB color space.
- Center the face with some space around the head and shoulders.
- Use similar framing, lighting, and background treatment across all six images.
- Keep each file below 2 MB when practical.
- Do not add names, text, borders, logos, or transparent areas.
- Confirm each person has agreed to have their image used in the app.

## Upload steps

1. Crop and export each image using the guidelines above.
2. Rename the files exactly as listed. Filenames are case-sensitive when deployed.
3. Place the six files in this folder.
4. Refresh the app. The allocation screen randomizes their display order.

If a file is missing or cannot be loaded, the app automatically displays
`public/interns/placeholder.svg`.
